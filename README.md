# E-Commerce Frontend Project

An e-commerce frontend application built using React and Redux Toolkit. It includes authentication, product listing, cart functionality, and protected routes.

---

## Live Demo
https://your-live-link.vercel.app

---

## Features

- User Register & Login
- Product Listing (API based)
- Product Details Page
- Add to Cart / Remove from Cart
- Update Quantity
- Cart Persistence (LocalStorage)
- Protected Routes

---

## Tech Stack

- React
- Redux Toolkit
- React Router DOM
- Tailwind CSS
- Fake Store API

---

git clone <>
